# Roadmap

Росте знизу, по мірі надходження задач. Пункт стає `[x]` тільки після підтвердження людини (крок 4, CLAUDE.md).

## В роботі

- [ ] Модуль товарів (products) — картка товару за зразком `Image.png`. UI зверстано на моках, чекає звірки з людиною.
- [ ] Модуль налаштувань (settings) — вкладка «Довідники» зверстана (список-навігація, поки без сторінок самих довідників і без БД).

## Беклог

- [ ] Авторизація (email + пароль), сесії
- [ ] Список товарів (сторінка `/products`)
- [x] Підключення PostgreSQL + Drizzle, таблиці products/product_skus (+ product_photos/product_measurements/tags), RLS — див. `db.md`
- [x] Категорії товару (settings): таблиця `categories` (ієрархія, RLS), повний CRUD (створення/редагування/видалення/зображення), зв'язок `products.category_id`, реальний лічильник товарів на категорію, хлібні крихти й вибір категорії товару за реальним деревом — див. `modules/settings.md`, `modules/products.md`
- [x] Список товарів (сторінка `/products`) — пошук/фільтри/пагінація/видалення на реальній БД, «Додати товар» створює чернетку, «Імпорт» поки заглушка; картка товару — кнопка «Створити товар»/«Редагувати» зберігає всю форму (ім'я/статус/категорія/ціни/характеристики/метадані/теги) одним запитом — підтверджено — див. `modules/products.md`
- [x] Довідник «Кольори» (settings → Довідники → Кольори): таблиця `colors` у БД (тенант-скоуповано, RLS), CRUD (квадратик-зразок = нативний color picker, синхронізований з HEX-полем, назва), 30 кольорів засіяно англ. назвами; картка товару бере кольори звідси (раніше — хардкод `COLOR_OPTIONS`) — підтверджено — див. `modules/settings.md`
- [x] Довідник «Бренди» — 100 брендів засіяно (спершу `reference_items`, згодом перенесено в `custom_characteristics` — нижче) — див. `modules/settings.md`
- [x] Довідник «Валюти» (settings → Довідники → Валюти): власна таблиця `currencies` (код/символ/позиція/знаки після коми/курс/автооновлення, лише одна базова валюта — частковий UNIQUE у БД), «Оновити курс(и)» тягне з НБУ (лише по кліку, без cron, живий виклик перевірено), UAH/USD/EUR/PLN засіяно — підтверджено — див. `modules/settings.md`
- [x] «Довідники» розбито на групи «Характеристики товару»/«Системні»; попап create+edit для власних характеристик (ввід-тегами Enter); 3 перемикачі CRM/вітрина/фільтри й кнопка-кошик (видалити можна лише користувацькі) — прямо на плитці, не в попапі; **3 перемикачі — на всіх без винятку плитках групи «Характеристики товару»** (нова генерична таблиця `reference_dictionary_flags` для «Кольорів»/«Тип тканини та матеріал»/«Інструкція по догляду»/«Розміри та заміри»); Колекції/Сезон/Бренди/Теги/Посадка перенесено з `reference_items`/`tags` у `custom_characteristics` (реальні dev-дані мігровано без втрат, «Теги» — з ризиком, підтвердженим людиною, `decisions.md`); «Кольори» перенесено з окремої сторінки в попап; курсор уніфіковано (`cursor-pointer`) на всіх клікабельних плитках — підтверджено людиною — див. `modules/settings.md`
- [ ] Довідник «Тип тканини та матеріал» (settings → Довідники → Тип тканини та матеріал) за зразком-скріном людини: окрема сторінка з реальними таблицями `fabric_types`/`materials`/`care_instructions`+4 junction-таблиці (замість «просто назва» kind у `reference_items`) — 2 вкладки («Типи тканини»: master-detail, пошук+пагінація, склад/можливі матеріали/сезон/розтяжність/зображення схеми/догляд; «Матеріали»: CRUD за зразком «Кольорів»); «Рекомендації по догляду» — реальний тенант-керований довідник (назва+іконка), а не хардкод; «Категорії товарів» зі скріна свідомо не робили (пряма вказівка людини); засіяно 55 матеріалів за списком людини з розбивкою по 7 категоріях (`materials.category`, поки без UI-групування) — чекає звірки з людиною — див. `modules/settings.md`
