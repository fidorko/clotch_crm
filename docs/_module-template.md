```markdown

**Статус:** UI `готово` · Логіка `в роботі` · Бек `—` · БД `—`
**Маршрут:** /products
**Оновлено:** 2026-07-28

## Призначення
Каталог товарів із фільтрами.

## Файли
| Шлях | Роль |

| src/pages/Products.jsx | сторінка, збирає layout і сітку |
```

Статуси шару: `—` · `в роботі` · `готово`.

## Коли модуль переріс ліміт (розділ 0 `CLAUDE.md`)

Той самий принцип, що правило 9.6 для коду («файл переріс ~400 рядків — ріж»), застосовується і до доків: якщо файл модуля стабільно перетинає ліміт (120 рядків), винось самодостатню підобласть в окремий піддокумент `docs/modules/<name>-<sub>.md` (наприклад `settings-suppliers.md`). В основному файлі модуля лишай один рядок у «Файли» з посиланням на піддокумент і компактний підсумок замість повної історії в «Зроблено». Піддокумент **не** отримує власного запису в `map.md` — він частина того самого модуля, лише винесена фізично.
