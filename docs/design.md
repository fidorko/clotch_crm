# Design

Еталон: `Image.png` (картка товару, скріншот) — щільний data-насичений SaaS-стиль (Linear/Notion-подібний).

## Палітра

| Роль | Колір | Використання |
|---|---|---|
| Primary / dark | `#1A1D29` | заголовки, іконки сайдбару, основний текст |
| Accent | `#5D5FEF` | кнопки дій, активна вкладка, посилання, теги |
| Success | `#22C55E`-подібний зелений | бейджі «Активний», «В наявності» |
| Warning | жовтий/бурштиновий | бейдж статусу «Не активний» |
| Background (page) | `#F7F8FA` | тло сторінки |
| Background (surface) | `#FFFFFF` | картки, контентні панелі |
| Border | `#E5E7EB`-подібний світло-сірий | рамки карток, роздільники таблиць |
| Muted text | сірий `#6B7280`-подібний | другорядні підписи, лейбли полів |

Точні hex уточнюються під час верстки ui-kit, значення вище — орієнтир зі скріна.

## Теми
Обидві: світла (базова, за зразком) і темна. Темна тема будується як інверсія тієї ж палітри (dark surface `#1A1D29`-подібний, текст світлий, accent той самий `#5D5FEF`).

## Шрифт
Сучасний sans-serif без засічок (тип Inter).

## Стиль
Щільний (dense): компактні таблиці, мінімальні відступи, багато даних на екран. Не повітряний.
Скруглення карток/кнопок: невелике (~4-5px, `--radius: 0.3125rem` в `globals.css`).
Фокус на текстових полях (Input/Textarea/Select): **без синього/акцентного кільця чи рамки**. Той самий нейтральний бордер, що й у стані спокою, лише трохи темніший (`border-muted-foreground/40`). Правило вже в базових компонентах ui-kit — не додавай `focus-visible:ring`/`focus-visible:border-ring` окремо на інстансах.
Сайдбар: вузький, іконки без підписів.

## Мова інтерфейсу
Українська.

## Пріоритет пристрою
Десктоп. Мобільний — окремий застосунок (поза цим проєктом).

## Приклад компонентів зі зразка
- Хлібні крихти (breadcrumbs) над заголовком сторінки
- Статус-бейдж (пігулка, зелений фон + текст)
- Вкладки (tabs) з підкресленням accent-кольору для активної
- Таблиця варіантів SKU з інлайн діями (іконки редагувати/видалити)
- Картки-панелі з заголовком і сірою рамкою
- Нижня панель підсумкових метрик (іконка + число + підпис)
