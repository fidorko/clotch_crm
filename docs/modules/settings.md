# Модуль: settings

**Статус:** UI `в роботі` · Логіка `—` · Бек `—` · БД `—`
**Маршрут:** /settings
**Оновлено:** 2026-07-30

## Призначення
Сторінка налаштувань магазину: вкладки-розділи (вітрина, загальні, категорії товару, замовлення, довідники, склади, доставка, оплата, тарифний план). Наразі наповнено лише вкладку «Довідники» — список із 14 пунктів (Колекції, Сезон, Тип тканини та матеріал, Виробники, Постачальники, Інструкція по догляду, Розміри та заміри, Бренди, Країни, Валюти, Кольори, Одиниці виміру, Теги, Посадка), кожен веде до окремого довідника (сторінки самих довідників — ще не зроблені).

## Файли
| Шлях | Роль |

| src/app/settings/layout.tsx | layout з сайдбаром (той самий патерн, що й products/layout.tsx) |
| src/app/settings/page.tsx | сторінка, збирає header + вкладки, `defaultValue="references"` (єдина наповнена вкладка) |
| src/components/settings/SettingsHeader.tsx | хлібна крихта (одна, «Налаштування» — сторінка верхнього рівня, не вкладена) + заголовок |
| src/components/settings/SettingsTabs.tsx | список вкладок (`TabsList`/`TabsTrigger`), той самий стиль, що й `ProductTabs` |
| src/components/settings/ReferencesList.tsx | вкладка «Довідники» — одна картка, рядки `divide-y` (іконка + назва + шеврон), `href="#"` — сторінки довідників ще не зроблені |

## Використовує з ui-kit
Card, Tabs

## Дані
Список довідників — статичний масив у `ReferencesList.tsx` (14 пунктів, поки без переходу нікуди). БД не підключена, усе на фронтенді (свідомо, за постановкою задачі).

## Доступ
Ролі, яким доступний модуль: owner (поки єдина активна роль).

## Зв'язки
