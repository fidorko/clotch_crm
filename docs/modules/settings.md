# Модуль: settings

**Статус:** UI `в роботі` · Логіка `—` · Бек `—` · БД `—`
**Маршрут:** /settings
**Оновлено:** 2026-07-30

## Призначення
Сторінка налаштувань магазину: вкладки-розділи (вітрина, загальні, категорії товару, замовлення, довідники, склади, доставка, оплата, тарифний план). Наповнено дві вкладки: «Категорії товару» (таблиця структури каталогу — пошук, фільтр статусу, масове виділення/видалення, drag-handle для сортування, дії по рядку) і «Довідники» (список із 14 пунктів, кожен веде до окремого довідника — сторінки самих довідників ще не зроблені).

## Використовує з ui-kit
Card, Tabs, Table, Select, Input, Button, Badge, Checkbox (новий)

## Дані
«Категорії товару» — статичний масив `mockCategories` (`lib/mocks/categories.ts`). Довідники — статичний масив у `ReferencesList.tsx` (14 пунктів, поки без переходу нікуди). БД не підключена, усе на фронтенді (свідомо, за постановкою задачі).

**Нюанс Select з ui-kit:** якщо `value` довідника-опції не збігається з людським лейблом (тут — `"all"`/`"active"` тощо, а не сам текст), `SelectValue` треба явно дати render-функцію (`<SelectValue>{(value) => label}</SelectValue>`) — інакше показує сирий `value`. У `CategorySelectRow` (`ProductInfoPanel`) цього не було видно, бо там `value` і лейбл — той самий рядок.
