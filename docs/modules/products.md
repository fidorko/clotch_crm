# Модуль: products

**Статус:** UI `в роботі` · Логіка `—` · Бек `—` · БД `—`

**Оновлено:** 2026-07-30 (видима сітка SKU-матриці з першого рендеру, +Розмір/+Колір як окремі клітинки грід)

Картка товару: загальна інформація, фото, варіанти SKU (колір × розмір), залишки, статистика по товару. За зразком `Image.png`.

## Використовує з ui-kit
Sidebar, Button, Badge (variant success/warning/secondary), Card, Tabs, Table, DropdownMenu (з DropdownMenuCheckboxItem, DropdownMenuItem), Tooltip, StatTile, DetailRow, Select, SelectRow, NumberRow, TextRow, PriceModeRow, Combobox, Dialog, Switch, Textarea, Input

## Дані
Зараз: моки в `src/lib/mocks/products.ts` (`product.measurements`, `sku.cell`). Розмірна сітка (`ProductSizeChart.tsx`) — окремо захардкоджена, уніфікована таблиця (не прив'язана до товару чи категорії). Типи замірів — спільний тимчасовий довідник `lib/constants/measurement-types.ts` (поле `imageUrl` поки завжди порожнє — плейсхолдер-іконка в UI).
Планово: таблиці `products`, `product_skus` (див. `db.md`) — ще не створені, БД не підключена. Розмірна сітка й типи замірів — окремі довідники, ймовірно з прив'язкою до категорії/типу одягу; `imageUrl` на кожен тип заміру — окреме зображення-візуалізація (що саме міряти), з БД.
