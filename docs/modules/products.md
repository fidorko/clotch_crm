# Модуль: products

**Статус:** UI `в роботі` · Логіка `—` · Бек `в роботі` · БД `в роботі`
**Маршрут:** /products/[id]
**Оновлено:** 2026-07-30 (підключення PostgreSQL + Drizzle, сторінка читає реальні дані)

## Призначення
Картка товару: загальна інформація, фото, варіанти SKU (колір × розмір), залишки, статистика по товару. За зразком `Image.png`.

## Дані
Сторінка `/products/[id]` читає реальні дані з PostgreSQL через `getProductById(tenantId, id)` (`src/server/data/products.ts`) — таблиці `products`, `product_skus`, `product_photos`, `product_measurements`, `tags`/`product_tags` (детально — `db.md`). `tenantId` поки з dev-константи (`TODO(auth)`, `db.md`). Мок `src/lib/mocks/products.ts` лишається як джерело сіду (`npm run db:seed`), UI-код на нього більше не посилається (крім `selectedSku` — див. «Відкрито»).
Розмірна сітка (`ProductSizeChart.tsx`) — окремо захардкоджена, не прив'язана до товару/категорії. Типи замірів — тимчасовий довідник `lib/constants/measurement-types.ts` (`imageUrl` завжди порожній), кольори/розміри SKU-матриці — `lib/constants/sku-variant-options.ts`; жодне з трьох свідомо не нормалізоване в БД цього проходу (обґрунтування — `db.md`).
